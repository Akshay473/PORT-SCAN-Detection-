Lab Setup Guide & Kali Linux Command Reference

Complete step-by-step instructions for launching Nmap scans from Kali Linux, configuring log forwarders, and validating detections.

1. Kali Linux Nmap Cheatsheet

TCP SYN Stealth Scan (-sS)
nmap -sS -p 1-1000 -T4 192.168.1.150
Stealth Flag Anomaly Scans (-sN, -sF, -sX)
nmap -sN 192.168.1.150 && nmap -sF 192.168.1.150 && nmap -sX 192.168.1.150
UDP Port Sweep (-sU)
nmap -sU --top-ports 50 192.168.1.150
Low-and-Slow Evasive Scan (-T1)
nmap -sS -T1 --scan-delay 15s -p 21,22,80,443,3389 192.168.1.150

2. SIEM Ingestion Instructions

Splunk File Monitoring Configuration (`inputs.conf`)

[monitor:///var/log/suricata/eve.json]
sourcetype = suricata:eve
index = ids

[monitor:///var/log/iptables.log]
sourcetype = syslog:iptables
index = firewall

Elastic Filebeat Suricata Module Enable

sudo filebeat modules enable suricata iptables
sudo filebeat setup -e
sudo systemctl restart filebeat
